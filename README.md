# 모임 지도 (첫 버전)

초대한 사람끼리 지도 위에서 말풍선으로 대화하는 모임용 웹앱입니다.
위치는 **'모임 시작'을 눌렀을 때만** 공유되고, 종료하거나 앱을 닫으면 지워집니다.

## 지금 되는 것
- 닉네임 + 방 코드로 입장, 초대 링크 공유
- 지도(OpenStreetMap) 위에 말풍선 남기기, 대화 목록
- 모임 시작/종료 버튼 (시작했을 때만 내 위치 공유)

## 모드
| 모드 | 연결 범위 | 설정 |
|---|---|---|
| 데모 모드 (기본) | 같은 기기·같은 브라우저의 탭끼리 | 없음 (index.html만 열면 됨) |
| Firebase 모드 | 폰·PC 등 여러 기기 | `FIREBASE_CONFIG`에 값 입력 |

## 혼자 테스트하는 법 (데모 모드)
1. 브라우저 탭 2개에서 같은 주소를 엽니다.
2. 첫 탭에서 '새 모임방 만들기', 두 번째 탭은 같은 방 코드로 입장합니다.
3. 한쪽에서 쓴 말풍선이 다른 탭에도 뜨면 정상입니다.

## 여러 기기 연결 (Firebase)
1. Firebase 콘솔에서 프로젝트를 만들고 Realtime Database를 생성합니다.
2. 웹 앱을 추가해서 나오는 설정값(`apiKey`, `databaseURL` 등)을 `index.html`의 `FIREBASE_CONFIG = null;` 자리에 객체로 붙여넣습니다.
3. 데이터베이스 규칙을 설정합니다. (아래 주의 참고)
4. 무료 한도와 요금 조건은 Firebase 공식 페이지에서 직접 확인하세요. (이 문서 작성 시 확인하지 못했습니다.)

## 주의 (꼭 읽기)
- **규칙(보안)을 열어둔 테스트 상태로 공개 배포하면 방 코드를 아는 누구나 읽고 쓸 수 있습니다.** 처음엔 가까운 지인과만 쓰세요.
- 방 코드가 곧 입장권입니다. 링크를 아무 곳에나 올리지 마세요.
- 신고·차단·강퇴 기능은 아직 없습니다. 모르는 사람이 모이는 모임에 쓰기 전에 필요합니다.
- 위치정보 관련 법령(위치정보법, 개인정보보호법) 검토는 아직 하지 않았습니다. 일반 공개 전에 확인이 필요합니다.
- 화면이 꺼졌을 때 위치가 계속 갱신되는지는 브라우저와 기기에 따라 다를 수 있고, 실기기 테스트를 하지 않았습니다.
- 지도 타일은 OpenStreetMap 공용 서버를 씁니다. 사용자가 늘면 사용 조건 확인과 별도 타일 서비스가 필요할 수 있습니다.

## 아직 안 한 것
사진, 푸시 알림, 로그인, 신고·차단, 말풍선 겹침 정리, 수익화
